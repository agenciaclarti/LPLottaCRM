# Landing page — Lotta CRM

Projeto estático em HTML, CSS e JavaScript puro. Pode ser aberto diretamente pelo `index.html` ou publicado no GitHub Pages, sem build.

## Imagens do produto

Adicione as capturas reais mantendo exatamente estes nomes:

- `assets/screenshots/dashboard.png`
- `assets/screenshots/eventos.png`
- `assets/screenshots/financeiro.png`

Os placeholders somem automaticamente quando os arquivos existem. Use imagens PNG ou WebP otimizadas, mantendo boa resolução para preservar a legibilidade da interface.

O símbolo existente em `icons/` é usado como marca provisória. Quando o logo oficial for enviado, substitua as imagens dentro dos links com a classe `.brand`.

## Antes de publicar

- Atualize o `CTA_TARGET` no início de `js/main.js` com o destino comercial definitivo.
- Atualize a URL canônica em `index.html`.
- Substitua `og:image` por uma imagem social horizontal oficial quando ela estiver disponível.
- Troque os links legais do rodapé quando as respectivas páginas existirem.

## Tipografia

Títulos usam Outfit. Textos usam Manrope como alternativa visual próxima à Geist, que não está disponível de forma estável no Google Fonts.
